# AI-7：現有紀錄的離線價值

本次只重播舊棋譜、讀取摘要與執行模型推論。沒有 PPO 更新、重新訓練、
重建過去梯度、使用 symmetry reserved 集或修改 GameCore。

結果：`benchmark-results/ai7-selfplay/existing-records/20261114-v1/`。

## 已確認的保存範圍

第二輪九次訓練保存 126,165 筆完整對局摘要、45 個不同階段 checkpoint。
每次訓練只保存四盤完整 training replay，合計 36 盤，約占摘要局數 0.029%。
這些是依進度選取的 batch game-0，不是全期隨機抽樣，不能估計整體戰術覆蓋率。

36 盤均以原始 deck 與動作透過 Core 重播，finalState 與完整 publicHistory
逐一比對通過。只統計 learner 座位，共 4,438 次決策；完全明子的局面才進行
確定性一手勝利／下一手防守分類，含暗子局面是未分類，不是沒有戰術機會。

| 項目     | 機會決策數 | 來自幾盤棋 | 當時實際選對 |
| -------- | ---------: | ---------: | -----------: |
| 立即勝著 |         60 |         10 |            5 |
| 立即防守 |         85 |         10 |           50 |

同盤反覆出現的機會不是獨立樣本。勝著與防守互斥；防守局面沒有立即勝著，
並有安全與不安全選項。安全只代表不讓對手下一手立即終局獲勝。

## 現有紀錄直接支持的觀察

- 60 次勝著機會中，35 次出現在最終和棋的對局，當時均未選中勝著。
  其餘 25 次出現在最終獲勝的對局，其中五次選中立即勝著。
  所以可以檢查具體「錯過後和棋」與「錯過但後來仍贏」的例子；不能把
  35 次說成 35 盤，也不能推論錯過勝著必然導致和棋。
- 全部摘要的和棋共 88,659 局，其中 NO_PROGRESS 88,540 局、
  CHASE_STALEMATE 119 局。這是終局原因；反覆走棋診斷不等於另有一個
  「repetition draw」規則。NO_PROGRESS 約占和棋 99.87%。
- 同樣已出現過的戰術局面，用五個階段模型重新計算，可以看到局部機率起伏。
  例如 baseline seed4011 的 15 個勝著機會：初始 8.27%、1.82M 時 22.98%、
  最終 6.84%。這不是獨立戰術集上的普遍能力結論，也不是單次更新因果證據。
- retrospective scoring 使用每個 run 自己的棋譜，因此不同 treatment 的
  分數不能直接排名。公平比較仍用已建立的共同 400 局面集或固定對手評估。

## 免訓練仍能做的研究

1. 從這些具體例子整理錯過勝著、連續防守失誤與 NO_PROGRESS 轉換失敗的
   case studies，對照早期與後期模型的動作機率；不將標籤送入訓練。
2. 使用現有 45 個模型對共同公開狀態做能力保留、動作偏好及對稱性分析。
   可以比較「維持原有能力」與「換位置失效」，不需要 optimizer。
3. 使用凍結模型進行交叉對戰，檢查版本互剋與對手特化。這需要新推論對局與
   計算預算，但不需要訓練；目前尚未執行。
4. 利用全部訓練摘要按階段、對手與終局類型分析資料組成。訓練對手持續變動，
   因此訓練 W/D/L 不是固定棋力評估。

## 不能從舊資料可靠回答的問題

- 全部 126,165 局真正遇到多少戰術機會：大多只保存摘要，沒有逐步走法。
- 每次錯過機會時的原始 log probability、value、advantage 與梯度：
  完整棋譜不含這些數值，保存的中途 checkpoint 也不是當時每次更新的模型。
- 負梯度 cosine 是否造成某次戰術錯誤：舊診斷只有固定 probes 與取樣 minibatches，
  不能把關聯解釋成完整因果對齊。

deck seed 不等於走法紀錄；還需要當時策略與 RNG。跨越未保存的 PPO 更新來
精確重現全部棋譜通常需要重跑優化，超出本次「不重新訓練」範圍。不能以
最終模型重下同 seed 的棋，冒充原本訓練軌跡。

## 重現

在 repository 根目錄執行。工具拒絕覆寫既有主要結果；如重新執行，須選擇新
output 路徑並同步修改 Python 工具的 output 設定。

```sh
node --import ./scripts/ai-eval/register.mjs scripts/ai7/analysis/record_coverage.ts \
  benchmark-results/ai7-selfplay/existing-records/20261114-v1
.venv/bin/python -m scripts.ai7.analysis.existing_records
```

`replay-coverage.json` 保存公開局面與分類；`analysis.json` 保存各 run 摘要、
各階段機率與來源摘要 SHA-256；`research-review.md` 提供表格。
所有模型推論只輸入 `PublicInput`，不輸入 deck、seed、標籤或對局結果。
