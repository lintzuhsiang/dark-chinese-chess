# 第二輪模型：獨立戰術與對稱性評估

這是評估，沒有訓練或選擇 checkpoint。第一階段 20 個獨立局面通過旋轉轉換驗證後，第二階段使用 200 個立即勝著與 200 個立即防守局面，評估 45 個 checkpoint。另保留 100+100 個新局面，未對任何模型評分。

每個局面來自不同 seed 的 Uniform Random 合法對局；以忽略歷史的公開棋盤及其旋轉軌道去重。戰術集完全明子、最多六子。結果適用於此抽樣分布，不能代表所有暗棋戰術。旋轉不交換座位或顏色。

## 解讀

- 三組都存在明顯的對稱性差異；這不能僅歸咎於八個舊 Probe。Baseline 最終勝著 Gap 約 12.42 pp、防守約 28.82 pp。
- 這批新局面的平均立即勝著能力仍接近隨機。Baseline 與高 Random 組三個 seeds 的初始→最終勝著變化區間均包含零。低 LR 僅一個 seed 的小幅改善區間排除零，且屬多重探索比較。
- 沒有重現舊 Probe 上的普遍大幅退化，不能把少量固定局面的退化直接當成整體戰術能力崩潰。但這也不否定個別舊局面確實退化，且不代表新分布完全沒有局部退化。
- 防守的改善有限且 seeds 不一致；Baseline 一個 seed、低 LR 兩個 seeds 的條件式區間排除零，不足以宣告方法普遍較強。
- 低 LR 的 Gap/TV 較小，但勝著能力也未明顯更好。接近均勻策略天然較對稱，穩定性不是棋力。
- 棋盤位置、固定 action head、公開 reference 與 history 座標仍一起變化；本實驗沒有隔離出哪個表徵成分是原因。
- 下一步可獨立測試對稱增強，並以能力與實戰結果為主要驗證，Gap/TV 為機制指標。也應量測訓練軌跡對這類機會的覆蓋率。未執行任何新訓練。

完整逐局、每個 checkpoint 的數值與區間見 stage2-evaluation.json；相鄰 checkpoint 的配對變化見 adjacent-changes.json。這些檔案包含未校正的探索分析，不能以挑選最好中途 checkpoint 的方式宣告成功。

## 保留集

reserved.json 有 100 個勝著、100 個防守局面；只作 Core 與去重驗證，沒有對它執行模型推論。它是在本次模型評估完成後才產生，應留給事先定義的後續確認測試。
