每列64局完整新遊戲，當前模型自己採樣行為；Random與凍結自身分開測。collect(training=True)只開啟軌跡記錄，本分析不呼叫optimizer。數千個決策共享64個終局結果，不能當數千個獨立樣本；未提供誤導性的逐決策顯著性。Random的對手分布不同於訓練混合池，凍結自身也僅覆蓋混合池的一部分，不能完全替代訓練分布診斷。

EV=1−Var(y−V)/Var(y)。大量和局會縮小分母、增加估計波動；所有回報皆0時EV應無定義。這裡應同時查看非零的回報變異與MSE，不能以大量0為由忽略預測錯誤。正相關但EV負，可能表示能粗略排序、卻預測幅度太大；EV對常數偏移不敏感，因此EV正也可能因校準偏差而MSE比預測0差。原始數據提供五等分校準表、勝和負分層MSE及逐局等權MSE。

原始crossfit_constant_mse使用座位分割，並非獨立deck交叉驗證，本報告不以該欄做推論。oracle_constant_mse是同樣本最佳常數的描述性參考，並非可部署的預測器。

樣本來自每個MLP final固定保存的兩盤正式評估實戰，僅保留ply≥80且存在往返／重複合法動作的學習方局面。這是final軌跡條件下的局面選樣，不是所有長棋局的無偏抽樣。重複動作由Core合法清單篩選，再比較公開棋盤、下一座位及顏色指派；不修改合法性或重複規則。

初始近均勻策略本來就有重複機率，不能把每次重複都歸因於學習。相同局面上final的往返／重複機率若升高，則可證明模型偏好確實改變，不能全由對手那次隨機抽樣解釋。但某段實際棋譜的因果來源仍同時包含雙方選擇與局面限制，無法硬分成「純隨機」與「純學得」兩類。最高機率也不等於必然選擇。

## 建議

先調查checkpoint間的策略機率震盪與actor/critic梯度耦合，不直接把問題歸因於步數不足。保持終局獎勵，分別控制測試較小learning rate／較少PPO epochs、不同lambda，以及更密的歷史對手快照；一次只改一個因素，使用新訓練seed與新確認測試集。不要用本次固定探針去挑最佳模型後再宣稱泛化改善。

本次未證明某個改法必然有效，亦未啟動新訓練。
